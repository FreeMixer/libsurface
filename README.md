# libsurface

libsurface: the device behaviour of motorised control surfaces (motor-fader policy, touch,
bank window, board shadow and replay, meter steps), written once in C for every surface and
every host. Work in progress, see [FreeMixer/libdiginet#29](https://github.com/FreeMixer/libdiginet/issues/29).
